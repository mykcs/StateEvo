# Wish · StateEvo

This is a **discovery router**, not a second scientific proposal. The actual published scope and research goal are described in the [project README](../../README.md) and its [publication manifest](../../PUBLICATION_MANIFEST.json).

- **Durable research intent:** study whether agents learn from interaction experience, whether externally described skills can become retained parameter capabilities, and whether sequential learning preserves older abilities.
- **Evidence boundary:** experiments, historical OpenEvo-derived code, protocol designs and separately audited results have different authority. A planned experiment is not a completed result; public records are limited to the manifest.
- **Current work:** [Current handoff](../agents/current/README.md) and live GitHub [PRs](https://github.com/mykcs/StateEvo/pulls) / [Issues](https://github.com/mykcs/StateEvo/issues).
- **Engineering:** [Dev](../dev/README.md). Shared semantics: [Wish protocol](https://github.com/mykcs/.agents/blob/main/docs/agents/WISH_PROTOCOL.md).

Do not duplicate private datasets, credentials, unpublished conclusions, or the project's scientific receipts here.
